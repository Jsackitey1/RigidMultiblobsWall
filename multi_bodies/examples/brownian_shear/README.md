# Single particle in shear with Brownian motion

From the repository root:

```sh
python3 multi_bodies/examples/brownian_shear/run_demo.py
```

This runs the existing dense first-order RFD Brownian integrator with background
shear and writes `multi_bodies/data/brownian_shear/combined_motion.mp4`.
Rerunning overwrites this example's output only. The two views show the same
saved 3D trajectory, without animation interpolation. Yellow lines project a
body-fixed axis using the saved quaternions; their projected length can change.
Gray arrows indicate imposed shear, not the particle-disturbed fluid field.
The 201 saved frames play at 20 FPS (10.05 seconds), representing 20 nondimensional
time units. Frame times in the renderer assume the supplied dt=.01, n_save=10.

The sphere has 12 blobs, blob radius .25 and envelope radius 1.25. Parameters
are nondimensional demonstration choices: shear rate .35, kT=1, eta=1,
g=.01, initial center (0,0,4), seed 42. The floor is no-slip; all axes are
nonperiodic. The viewing box introduces no side walls. Wall repulsion and gravity
remain active. Thermal translation and rotation are generated by the body's
hydrodynamic mobility, including the RFD thermal drift.

The dense solve already includes background flow through the blob slip RHS;
the RFD mobility difference supplies thermal drift, not an extra shear forcing.
Support is deliberately limited to stochastic_first_order_RFD_dense_algebra
with nonperiodic boundaries: its dense mobility routines do not implement
periodic image sums. Other stochastic shear schemes remain rejected. Dense
algebra is suitable for this small demonstration, not a scalable suspension run.

Tests verify the combined one-step shear response against an independent saddle
solve, zero-temperature behavior, translational/rotational noise covariance,
and rejected unsupported configurations. These are implementation checks, not
physical calibration or timestep/spatial convergence of a research experiment.
